2Project Overview & Goals

The Problem

  • Cheap models: $0.0008/1k tokens but limited reasoning
  • Expensive models: $0.015/1k tokens with full reasoning power
  • Status quo: Use expensive model for EVERY query

The Solution

Route queries based on complexity:

Query ↓ Complexity Analysis (0-100) ↓ Tier Selection ↓ Model Selection ↓ Cost Tracking ↓ LLM Call

Cost Impact

Scenario Cost (1000 queries) Distribution
Always Expensive $15.00 100% Opus
With Router $2.66 70% Haiku, 20% Sonnet, 10% Opus
Savings $12.34 (82%) -

3Architecture Deep Dive

System Flow:

User Query
    ↓
[Complexity Estimator] → Analyzes 5 factors (length, keywords, structure, context, punctuation)
    ↓
[Model Router] → Selects tier based on score
    ↓
[Metrics Recorder] → Tracks cost, usage, latency
    ↓
[Model Selector] → Picks specific model
    ↓
[Cost Estimator] → Calculates estimated cost
    ↓
[LLM Call] → Sends to actual LLM

Complexity Algorithm (5 Factors)

FACTOR 1: LENGTH (0-30 points)
  < 5 words   → 10 points   (very simple)
  5-15 words  → 20 points   (moderate)
  > 15 words  → 20-30 points (complex)

FACTOR 2: REASONING KEYWORDS (0-40 points)
  "why", "how", "compare", "analyze", etc.
  Multi-part questions ("and", "or")    → 15 points
  Reasoning verbs                        → 10 points
  Conditional logic ("if", "when")      → 10 points
  Negation ("not", "n't")               → 5 points

FACTOR 3: CONTEXT SIZE (0-20 points)
  1 point per 1000 characters of context
  Max 20 points at 20,000+ chars

FACTOR 4: SPECIAL PUNCTUATION (0-10 points)
  2 points per special char (?!:;)
  Max 10 points

FACTOR 5: CAPPED AT 100
  min(100, sum of all factors)

Routing Logic

def route(question, context_chars, force_tier=None):

    # Step 1: Estimate complexity (0-100)
    complexity = estimator.estimate(question, context_chars)

    # Step 2: Determine tier
    if force_tier:
        tier = force_tier  # Override (for testing)
    elif complexity < cheap_threshold (default 40):
        tier = CHEAP
    elif complexity < medium_threshold (default 70):
        tier = MEDIUM
    else:
        tier = EXPENSIVE

    # Step 3: Select model from tier
    model = select_model_from_tier(tier)

    # Step 4: Estimate cost
    input_cost = (len(question) / 4 / 1000) * model.cost_per_1k_input
    output_tokens = min(complexity * 10, model.max_input_tokens)
    output_cost = (output_tokens / 1000) * model.cost_per_1k_output
    total_cost = input_cost + output_cost

    # Step 5: Check budget constraints
    if query_budget_usd and total_cost > query_budget_usd:
        log warning about budget exceeded

    # Step 6: Return decision
    return RoutingDecision(
        model=model,
        complexity_score=complexity,
        estimated_cost=total_cost,
        reason="explanation"
    )

9Integration Guide

Integration Pattern 1: Standalone Use

from router import ModelRouter, preset_anthropic_only

router = ModelRouter(preset_anthropic_only())

decision = router.route("Your question")
model_name = decision.model.name
cost = decision.estimated_cost

result = llm.call(question, model=model_name)

Integration Pattern 2: RAG Pipeline

from router import ModelRouter, preset_anthropic_only
from metrics import record_model_request, record_model_response

# Retrieve context
context = retrieve_documents(question)
context_chars = len(context)

# Route based on complexity + context
router = ModelRouter(preset_anthropic_only())
decision = router.route(question, context_chars=context_chars)

# Track request
start_time = record_model_request(decision.model.name)
try:
    response = llm.answer(question, context, model=decision.model.name)
    record_model_response(
        decision.model.name,
        start_time,
        input_tokens=response.usage["input_tokens"],
        output_tokens=response.usage["output_tokens"],
        cost=decision.estimated_cost
    )
finally:
    # Ensure we record even if there's an error
    pass
