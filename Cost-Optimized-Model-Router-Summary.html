🎯 Project Overview

What Was Built

A production-ready intelligent query routing system that reduces LLM costs by 70-85% by automatically routing queries to appropriate model tiers based on complexity analysis.

The Problem

  • Cheap models (Haiku, Mistral): $0.0008/1k tokens - fast but limited reasoning
  • Expensive models (Opus, GPT-4): $0.015/1k tokens - powerful but costly
  • Current approach: Use same expensive model for ALL queries regardless of complexity

The Solution

Intelligently analyze each query's complexity (0-100 score) and route to the appropriate tier:

Complexity Score (0-100) ↓ Tier Selection (Cheap/Medium/Expensive) ↓ Model Selection ↓ Cost Estimation & Tracking ↓ LLM Call

💰 Cost Impact

Scenario Cost per 1000 Queries Savings
Always use expensive model $15.00 -
With intelligent routing (70% cheap, 20% medium, 10% expensive) $2.66 -
Savings - 82% ($12.34 saved)

🔧 How It Works

Complexity Estimation (5 Factors)

Factor Points Example
Question Length 0-30 Long questions = more complex (more reasoning required)
Reasoning Keywords 0-40 "explain", "compare", "analyze", "synthesize" = complex tasks
Question Structure 0-15 Multi-part questions with "and", "or", "but" = more complex
Context Size 0-20 Larger retrieved context = more integration work
Punctuation 0-10 Special chars (?!:;) indicate complex structure

Complexity Examples

Query Score Tier Model Cost
What is 2+2? 12 Cheap Haiku $0.0008
Explain machine learning 35 Cheap Haiku $0.0012
Compare and contrast approaches; discuss implications 52 Medium Sonnet $0.0036
Deep synthesis of quantum mechanics and relativity 87 Expensive Opus $0.0154

Routing Thresholds

  • Complexity 0-40: Route to CHEAP tier (Haiku: $0.0008/1k tokens)
  • Complexity 40-70: Route to MEDIUM tier (Sonnet: $0.003/1k tokens)
  • Complexity 70-100: Route to EXPENSIVE tier (Opus: $0.015/1k tokens)

📊 Architecture

User Query ↓ Complexity Estimator (0-100 score) ↓ Model Router (Select Tier) ↓ Model Selector (Pick Specific Model) ↓ Cost Estimator ↓ Metrics Recorder (Track Cost & Usage) ↓ LLM Call (With Selected Model)

Metrics Collected

  • ragstack_query_complexity - Complexity distribution histogram
  • ragstack_router_cheap_total - Count of cheap tier queries
  • ragstack_router_medium_total - Count of medium tier queries
  • ragstack_router_expensive_total - Count of expensive tier queries
  • ragstack_estimated_cost_total_usd - Total estimated cost
  • ragstack_request_latency_seconds - Response time distribution
  • ragstack_tokens_input - Input tokens per request
  • ragstack_tokens_output - Output tokens per request
  • Per-model performance metrics (latency, tokens)

💻 Quick Start

Installation

pip install -e ".[all]"

Basic Usage

from router import ModelRouter, preset_anthropic_only

# Initialize router
router = ModelRouter(preset_anthropic_only())

# Route a query
decision = router.route("What is AI?")

print(f"Model: {decision.model.name}")
print(f"Complexity: {decision.complexity_score}")
print(f"Cost: ${decision.estimated_cost:.6f}")

Start Metrics Server

python -m metrics_server_main

# Server runs at http://localhost:8000
# Access endpoints: /health, /metrics, /router/route, etc.

Run Tests

pytest tests/test_router.py -v

Run Examples

python -m router_example

🔌 Integration Patterns

Pattern 1: Standalone Router

decision = router.route(question)
response = llm.call(question, model=decision.model.name)

Pattern 2: With RAG

context = retrieve_documents(question)
decision = router.route(question, context_chars=len(context))
response = llm.answer(question, context, model=decision.model.name)

Pattern 3: With Metrics Tracking

start = record_model_request(model_name)
